# Sujith I — Portfolio

Static site (HTML + CSS + JS). No build step.

## Publish on GitHub Pages
1. Create a repo (e.g. `sujii07.github.io` for a root URL, or any name).
2. Upload everything in this folder (keep `assets/`, `.nojekyll`).
3. Repo → Settings → Pages → Deploy from branch → `main` / root.

## Edit content
Everything is at the top of `script.js` (PROJECTS, SERVICES, EXPERIENCE, SKILLS, CERTS, LINKS).
- Replace each project's `code:` URL with its exact GitHub repo link.
- Fill in the IoT project details.
- Swap `assets/*.svg` covers with screenshots if you like (update `cover:`).
